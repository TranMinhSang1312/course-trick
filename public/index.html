01 · CÀI ĐẶT

Cài extension bằng Load unpacked

1

Tải và giải nén file ZIP

Bấm nút tải bên dưới. Sau khi tải xong, nhấp phải file ZIP và chọn Extract All / Giải nén tất cả.

Tải file ZIP
2

Mở trang quản lý extension

Dán một trong hai địa chỉ sau vào thanh địa chỉ trình duyệt rồi nhấn Enter.

chrome://extensions
edge://extensions
3

Bật Developer mode

Bật công tắc Developer mode / Chế độ dành cho nhà phát triển ở góc trên bên phải.

4

Chọn Load unpacked

Bấm Load unpacked / Tải tiện ích đã giải nén, mở thư mục vừa giải nén và chọn đúng thư mục dist.

5

Mở Coursera

Đăng nhập Coursera, mở một khóa học và tải lại trang. Nút Course Trick sẽ xuất hiện ở góc dưới.

04 · LỖI THƯỜNG GẶP

Nếu extension chưa hoạt động

Không thấy nút Course Trick trên Coursera

Kiểm tra extension đang bật, mở đúng trang coursera.org rồi nhấn F5 để tải lại trang.

Chrome báo lỗi khi chọn thư mục

Bạn cần giải nén ZIP trước và chọn đúng thư mục dist, không chọn trực tiếp file ZIP.

Không nhận Premium sau thanh toán

Kiểm tra email Coursera hiện tại có trùng email trên đơn, sau đó bấm “Kiểm tra ngay” hoặc “Đã mua? Khôi phục Premium”.

Gemini không trả lời quiz

Vào Cài đặt, kiểm tra đã chọn phương thức Gemini và API Key vẫn hợp lệ. Sau đó tải lại trang quiz.
